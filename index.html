    설정

    채팅 전송과 연령 제한 채널 접속에는 네이버 로그인이 필요합니다. 읽기만 할 경우 로그인 없이 사용할 수 있습니다.

    방송이 시작될 때마다 새 파일을 만들고, 맨 앞에 방송 시작 시각·제목·카테고리를 적습니다. 방송 중 제목이나 카테고리가 바뀌면 그 시각과 함께 이어서 기록합니다. csv는 엑셀·스프레드시트에서 바로 통계를 내기 좋습니다.

    폴더를 바꾸면 지금까지의 기록을 새 위치로 복사하고, 앱을 다시 시작해야 적용됩니다.

    로그인 버튼을 누르면 네이버 공식 로그인 페이지가 새 창으로 열립니다. 비밀번호는 네이버에만 입력되며, 앱은 로그인 후 세션 쿠키만 저장합니다.

    문제 진단 (고급)

    채팅 전송이 안 될 때, 아래 버튼을 누른 뒤 15초 안에 채팅을 보내면 서버와 주고받은 원본 내용이 채팅창에 표시됩니다.

    수동 쿠키 입력 (고급)

    브라우저 개발자 도구 → Application → Cookies에서 NID_AUT, NID_SES 값을 직접 붙여넣을 수도 있습니다.
