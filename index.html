    채널 별명

    이 앱에서만 쓰는 이름입니다. 비우면 원래 채널명으로 돌아갑니다.

    메모

    나만 보는 메모입니다. 채팅에 📝 표시가 붙고, 올려 두면 내용이 보입니다.

    강조 표시

    이 유저의 채팅 줄에 고른 색을 입혀 눈에 띄게 합니다.

    폴더 색

    폴더 이름과 묶음 막대에 입힐 색입니다. 폴더가 여럿일 때 눈으로 구분하기 좋습니다.

    창 색

    창마다 색을 달리 해 두면 여러 채널을 열어 두어도 헷갈리지 않습니다.

    진하기는 창을 투명하게 만드는 것이 아니라, 고른 색을 얼마나 진하게 얹을지를 정합니다.

    사용 중인 프로필

    채팅 닉네임을 꾸며보세요
    내 활동 배지 보여주기

    눌러서 켜고 끕니다. 구독 뱃지를 빼고 2개까지 달 수 있고, 고른 즉시 치지직에 저장되어 다른 사람 화면에도 그대로 보입니다.

    통나무 파워

    보유 파워 –
    획득 기록

    받을 수 있는 파워는 앱이 알아서 수령합니다. 값이 달라져 있을 때만 한 줄씩 남기므로, 치지직에서 직접 받은 것은 다음 확인 때 한꺼번에 잡힙니다.

    표시한 유저

    범위

    전체 검색

    고른 채널에 모두 채팅한 적이 있는 시청자를 찾습니다. 채널은 몇 개든 더할 수 있고, 더할수록 조건이 좁아집니다.

    집계

    설정

    채팅 전송과 연령 제한 채널 접속에는 네이버 로그인이 필요합니다. 읽기만 할 경우 로그인 없이 사용할 수 있습니다.

    방송이 시작될 때마다 새 파일을 만들고, 맨 앞에 방송 시작 시각·제목·카테고리를 적습니다. 방송 중 제목이나 카테고리가 바뀌면 그 시각과 함께 이어서 기록합니다. csv는 엑셀·스프레드시트에서 바로 통계를 내기 좋습니다.

    폴더를 바꾸면 지금까지의 기록을 새 위치로 복사하고, 앱을 다시 시작해야 적용됩니다.

    로그인 버튼을 누르면 네이버 공식 로그인 페이지가 새 창으로 열립니다. 비밀번호는 네이버에만 입력되며, 앱은 로그인 후 세션 쿠키만 저장합니다.

    문제 진단 (고급)

    채팅 전송이 안 될 때, 아래 버튼을 누른 뒤 15초 안에 채팅을 보내면 서버와 주고받은 원본 내용이 채팅창에 표시됩니다.

    수동 쿠키 입력 (고급)

    브라우저 개발자 도구 → Application → Cookies에서 NID_AUT, NID_SES 값을 직접 붙여넣을 수도 있습니다.
