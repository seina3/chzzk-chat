# Chzzk Chat

치지직(chzzk.naver.com) 전용 데스크톱 채팅 클라이언트. [Chatty](https://chatty.github.io/)처럼 방송 채팅을 데스크톱에서 보기 위한 앱으로, Tauri 기반이라 가볍습니다 (OS 내장 웹뷰 사용, 실행 파일 ~10MB).

## 기능

- **채팅 수신** — 익명(로그인 불필요) 읽기, 접속 시 최근 채팅 50개 로드
- **이모티콘 렌더링** — 치지직 이모티콘을 이미지로 표시
- **뱃지** — 스트리머/매니저 표시, 구독 뱃지 이미지
- **후원(치즈) 하이라이트** — 치지직 후원 UI와 같은 금액 구간별 색상
  (1천 보라 / 1만 청록 / 10만 초록 / 50만 주황 / 100만 빨강), 고액 후원 강조 효과
- **가려진 채팅도 표시** — 클린봇이 거른 메시지는 `🤖 클린봇` 표시와 함께 내용을 그대로
  보여주고(사실상 클린봇 해제), 운영자가 블라인드한 메시지는 `🚫 블라인드` 표시 + 취소선
- **전체 채팅 기록** — 모든 채팅을 SQLite에 저장 (개수 제한 없음). 닉네임 클릭 시 그 유저의 저장된 **전체** 메시지를 검색/페이지네이션(100개씩 "더 보기")으로 조회. 유저는 고유 ID로 추적하므로 닉네임을 바꿔도 이력이 이어지고, 닉네임 변경 이력도 표시
- **다중 채널 동시 수집** — 등록한 모든 채널의 채팅을 화면에 띄우지 않아도 백그라운드로
  수집해 DB·txt 로그에 저장 (설정에서 끄면 보고 있는 채널만 수집)
- **집계** — 기간(1일/7일/30일/전체)·채널별로 후원 총액, 유저별·채널별 후원 순위,
  유저별 채팅 순위를 확인. 목록에서 지운 채널도 이름으로 표시
- **채널 우클릭 메뉴** — 채널 열기, 링크 복사, 별명 바꾸기, 목록에서 삭제
- **닉네임 변경 기록** — 유저가 썼던 닉네임과 각각의 사용 기간·횟수
- **후원 집계** — 🧀 후원 버튼에서 기간별(1일/7일/30일/전체)·채널별 후원 총액과
  건수·후원자 수를 확인하고, 유저별 합계 순위와 상세 내역을 조회.
  유저 기록 모달에서도 "🧀 후원만" 탭으로 그 사람의 후원 내역과 누적 금액만 모아볼 수 있음
- **txt 실시간 로그** — 수신 채팅을 채널별/날짜별 텍스트 파일에도 실시간 기록 (설정에서 끌 수 있음, 재접속 시 중복 기록 방지)
- **방송 정보 대시보드** — 제목 / 카테고리 / 시청자 수 / 업타임 실시간 표시
- **방송 시작 알림** — 저장된 채널이 방송을 켜면 OS 알림
- **네이버 아이디로 로그인** — 앱 안에서 네이버 공식 로그인 페이지를 열어 로그인하면 채팅 전송 가능 (쿠키 수동 입력도 지원)

## 빌드 (Windows 기준)

요구 사항:

1. [Node.js](https://nodejs.org/) 18+
2. [Rust](https://rustup.rs/) (stable)
3. Visual Studio Build Tools의 "C++를 사용한 데스크톱 개발" 워크로드
4. WebView2 런타임 (Windows 10/11에는 기본 포함)

```sh
cd chzzk-chat
npm install
npm run tauri dev     # 개발 실행
npm run tauri build   # 배포 빌드 → src-tauri/target/release/bundle/
```

Linux/macOS도 Tauri 요구 라이브러리만 설치하면 동일하게 빌드됩니다
([Tauri prerequisites](https://tauri.app/start/prerequisites/) 참고).

## 로그인 (채팅 전송)

채팅을 보내려면(그리고 연령 제한 채널에 접속하려면) 네이버 로그인이 필요합니다.

⚙ 설정 → **"네이버 아이디로 로그인"** 버튼을 누르면 네이버 공식 로그인 페이지가
새 창으로 열립니다. 2단계 인증·캡차 포함 평소처럼 로그인하면 앱이 세션 쿠키
(`NID_AUT`, `NID_SES`)를 자동으로 가져오고 창이 닫힙니다.
비밀번호는 네이버 페이지에만 입력되며 앱은 저장하지 않습니다.

브라우저에서 쿠키를 직접 복사해 넣는 수동 입력(설정 → 고급)도 그대로 지원합니다.

세션 쿠키는 이 PC의 앱 데이터에만 저장됩니다. 쿠키가 유출되면 네이버 계정
전체가 위험하니 절대 공유하지 마세요. 읽기 전용으로 쓸 경우 로그인하지 않아도 됩니다.

## 저장 데이터 위치

Windows 기준 앱 데이터 디렉터리는 `%APPDATA%/dev.chzzkchat.app/` 입니다.

- 채팅 DB: `chzzk.db` — 유저별 전체 기록 조회에 사용.
  삭제·블라인드된 메시지도 **원문 그대로** 남고 가려짐 사유만 따로 기록된다
- txt 로그: `logs/<채널명>/<YYYY-MM-DD>.txt` — `[HH:MM:SS] <닉네임> 내용` 형식,
  후원은 `[후원 N치즈]` 태그 포함, 이모티콘은 `:이모티콘id:` 텍스트로 기록.
  저장 폴더는 설정에서 변경 가능하며 ("폴더 선택"), "열기" 버튼으로 탐색기에서 바로 열 수 있음
- 채널 목록 / 로그인 쿠키 / 설정: 웹뷰 localStorage (재부팅 후에도 유지)

## 주의: 비공식 API

이 앱은 치지직의 **비공식** API와 채팅 프로토콜(웹 클라이언트가 쓰는 것과 동일)을 사용합니다. 네이버가 프로토콜을 변경하면 동작이 깨질 수 있으며, 그 경우 `src/chzzk/` 아래 코드를 수정해야 합니다. 프로토콜 참고 구현: [kimcore/chzzk](https://github.com/kimcore/chzzk), [chzzkpy](https://github.com/gunyu1019/chzzkpy).

## 개발 메모

- `npm run check:offline` — npm 의존성 설치 없이 타입체크만 실행
  (`types-stub/`의 플러그인 API 스텁 사용)
- `node scripts/gen-icons.mjs` — 플레이스홀더 아이콘 재생성.
  제대로 된 아이콘으로 교체하려면 `npm run tauri icon <1024px.png>`
